## Updates

* Send additional IMU data (acceleration, angular velocity, linear acceleration) instead of only pitch, roll, and heading.
* Include calibration status from the IMU on the OLED for reliability feedback.
* Display error flags or sensor health information for debugging.
* Add graphical visuals (tilt bars, 3d rover display) instead of only numbers.
* Implement multiple display modes (orientation view, raw data view, debug view).
* Add filtering in code for smoother pitch and roll values.
* Add ability to log and stream IMU data for detailed analysis.
* Code for and display additional info like speed for better motion insight.
